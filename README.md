# Rock Paper Scissors Game

## Lab Session – Rock Paper Scissors Mobile Application

During this lab session, we developed a Rock Paper Scissors mobile application using **Visual Studio Code, React Native, and Expo**.

### Features Implemented

- Created a mobile application with tab navigation using Expo Router.
- Developed a Play Game screen with Rock, Paper, and Scissors options.
- Implemented computer selection using random number generation.
- Added game logic to determine the winner, loser, or draw.
- Created a scoreboard to track wins, draws, and losses.
- Added a Reset Game button to restart the game and clear the scores.
- Developed a Rules screen to explain the rules of the game.
- Used React Native components and StyleSheet to design the user interface.

### Technologies Used

- Visual Studio Code
- React Native
- Expo
- TypeScript (TSX)
- Expo Router
- React Hooks (`useState`)
- Ionicons

### Learning Outcomes

Through this lab session, we learned how to build a simple interactive mobile application, manage component states using React Hooks, handle user interactions, implement basic game logic, and navigate between screens using Expo Router.
